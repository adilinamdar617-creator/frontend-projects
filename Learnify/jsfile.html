# What is JavaScript?

JavaScript (JS) is a programming language used to make websites
**interactive and dynamic**. While HTML gives structure and CSS
gives design, JavaScript gives **life** to a webpage.
It allows a website to react to user actions like:
* Clicking buttons
* Filling forms
* Showing alerts
* Updating content without refreshing the page
Without JavaScript, websites would only be static pages (only text
and images). ---

# Why JavaScript is Important

Today, almost every website on the internet uses JavaScript.
Examples:
* Login systems
* Dark mode toggle
* Image sliders
* Pop-up messages
* Online shopping carts
* Live search suggestions
JavaScript runs directly inside the **browser** (Chrome, Edge,
Firefox), so users don’t need to install anything. ---

# What JavaScript Can Do

JavaScript can:
* Change HTML content
* Change CSS styles
* Validate forms (check email, password etc.)
* Show/hide elements
* Create animations
* Communicate with servers (without page reload)

# What is JavaScript?

JavaScript (JS) is a **high-level programming language** used to control the behavior of a webpage.
It makes a website interactive instead of just showing static content.
A normal webpage only shows text, images, and design.
JavaScript allows the page to **think and react** to the user.
Example:
* Clicking a button and something appears
* Form showing “Password is too short”
* Menu opening on mobile screen
* Live search suggestions
All of these are done using JavaScript.

# Where JavaScript Runs

JavaScript mainly runs inside a **web browser** such as:
* Google Chrome
* Microsoft Edge
* Firefox
* Safari
So the user does not need to install anything.
When a website loads, the browser reads the JavaScript and executes it automatically.
Today JavaScript can also run **outside the browser** using Node.js (used for backend/server).

JavaScript History

Created by Tim Berners-Lee in 1991.

# How JavaScript started (1995)

In the early internet, websites were only HTML pages.
They could show text and images, but users could not interact with them. Pages were boring and static.
A company called Netscape wanted websites to become interactive.
So they asked a programmer Brendan Eich to create a new language for web browsers.
He created the first version of JavaScript in just 10 days in 1995.

# First name was NOT JavaScript

Originally, the language was called Mocha
Then it was renamed LiveScript
Later Netscape changed the name to JavaScript to make it sound similar to the popular language Java (for marketing).
But important:
Java and JavaScript are completely different languages.

Early problems (1996–2000)

Soon many browsers appeared:
Netscape Navigator
Internet Explorer
Each browser supported JavaScript differently.
So a script working in one browser often did not work in another.
Developers had big problems.
To fix this, an official standard was created called ECMAScript.
From that point, JavaScript followed common rules.

# The big comeback (2005)

For some years JavaScript was used only for small things like alerts and form checking.
Then a technology called AJAX appeared around 2005.
Now websites could update information without reloading the page.
Because of this, modern websites were born:
Google Maps
Gmail
Facebook (early versions)
JavaScript suddenly became very important.

# Modern JavaScript (2009 → Today)

In 2009, a major change happened: Node.js was introduced.
Before this:
JavaScript worked only inside the browser.
After Node.js:
JavaScript could run on servers and build full applications.
Now JavaScript can create:
websites
mobile apps
games
desktop software
backend servers
Today
Today JavaScript is:
one of the most popular programming languages in the world
used by almost every website on the internet
If you open YouTube, Instagram, Amazon, or Google —
JavaScript is running there.

# Short summary

1995 → Created by Brendan Eich at Netscape
First names → Mocha, then LiveScript
Renamed → JavaScript
Standard created → ECMAScript
2005 → Modern interactive websites started
2009 → Node.js made it a full programming language
JavaScript changed websites from static pages into real web applications.
