HTML Home

Welcome to the HTML learning section.
HTML stands for **HyperText Markup Language**. It is the basic language used to create web pages. Every
website on the internet is built using HTML. It provides the structure of a webpage and tells the
browser what to display, such as headings, paragraphs, images, links, and lists.
HTML is not a programming language. It does not perform calculations or make decisions. Instead, it
organizes and describes the content of a webpage. You can think of HTML as the **skeleton of a
website**.
When you open any website, the browser reads the HTML file and shows the page content on the screen.
Without HTML, a website cannot exist because there would be nothing for the browser to display.
In web development:
* HTML creates the structure
* CSS designs the appearance
* JavaScript adds behavior and interactivity
HTML is the first step in learning web development. It is easy to understand and beginner-friendly, which
is why every web developer starts with HTML before learning CSS and JavaScript.
In this section you will learn:

* What HTML is

* How web pages are structured
* Basic elements like headings and paragraphs
* Links and images
* Lists and page organization
After learning HTML, you will be able to create your own simple web pages.

HTML Introduction

HTML (HyperText Markup Language) is the standard language used to create web pages. It tells the web
browser how the content of a page should be arranged and displayed on the screen.
HTML uses small labels called *tags* to describe different parts of a webpage. These tags identify
headings, paragraphs, images, links, tables, and many other elements. The browser reads these tags and
then shows the page to the user in a proper format.
When you visit any website, your browser first receives an HTML file. The browser understands the HTML
instructions and builds the page layout you see, such as titles at the top, text in the middle,
navigation menus, and images in different sections.
HTML alone does not make a website look beautiful and it does not make it interactive. Its main job is
structure and organization. It arranges the content in a logical order so the browser knows what each
piece of content represents.

In web development:

* HTML provides the structure of the webpage
* CSS adds design, colors, and layout
* JavaScript adds actions and interactivity
Because of this, HTML is considered the foundation of web development. Before learning styling or
programming, every beginner first learns HTML to understand how webpages are built.
After learning HTML, you will be able to create simple web pages that contain headings, text content,
images, links, and basic page sections. This knowledge becomes the base for learning CSS and
JavaScript later.

What Does HTML Do?

HTML tells the web browser what content a webpage has and how it is arranged.
It does not make the page stylish and it does not make it interactive.
Its job is only to show and organize the content.

What HTML actually does

HTML creates the structure of a webpage.
It lets the browser understand:
this is a heading (title)
this is a paragraph (text)
this is an image
this is a link
this is a list
this is a section of the page
So when you open a website, the browser reads HTML first and then displays the page.

Simple real-life example

Think of a house:
HTML → walls, rooms, doors (structure)
CSS → paint, colors, decoration
JavaScript → electricity, switches, fan working
Without structure, the house cannot exist.
Without HTML, a webpage cannot exist.

Examples of what HTML shows on a website

Using HTML you can:
display text and articles
show images
create buttons
add links to other pages
create navigation menus
embed videos
create forms (login, signup, contact)

Important point

HTML is not a programming language.
It does not calculate, think, or make decisions.
It only describes the content so the browser knows what to display.

In one line

HTML builds the basic structure of a webpage and shows the content to the user.

HTML Example

Imagine you open a simple webpage.
At the top you see a big title:
“Welcome to My Learning Website”
That title is created using HTML.
Below it you see a paragraph explaining the website:
“This website helps beginners learn HTML, CSS and JavaScript.”
That text is also placed using HTML.
Under the paragraph there is an image (maybe a computer or coding picture).
HTML tells the browser to show that image on the page.
Then you see a blue clickable text:
“Go to CSS Page”
When you click it, it opens another page.
That clickable link is made using HTML.
At the bottom you see a form:
a box to enter your name
a box to enter your email
a submit button
HTML creates these input boxes and the button.

What HTML did in this page

HTML:
showed the heading
displayed the paragraph
added the image
created the link
created the form
It only placed the content and structure.
The colors and design would come from CSS.
The button actions and checking would come from JavaScript.

Simple understanding

HTML is used to put content onto a webpage so the browser can display it to the user.

HTML History

Created by Tim Berners-Lee in 1991.

HTML (HyperText Markup Language) was created to help people share and read information on the internet.
In 1991, a scientist named **Tim Berners-Lee** introduced HTML while working at CERN (a research
organization). He wanted researchers to easily open documents and move from one document to another
using clickable links. This idea became the World Wide Web.
The first version of HTML was very simple. It only supported basic text, headings, and links. There were
no colors, no layouts, and no images like modern websites. Pages looked plain and similar to digital
documents.
As the internet became popular, HTML improved over time. New features were added so websites could include
images, tables, and better organization. Different versions of HTML were released, each
adding more capabilities for web developers.
Later, CSS was introduced to handle design and styling, and JavaScript was introduced to add
interactivity. HTML remained responsible for the structure of the webpage.
A major update called **HTML5** was released in 2014. It allowed websites to play video and audio directly
in the browser and made modern websites faster and more powerful. After HTML5, websites
could support animations, media, and mobile devices much more easily.
Today, HTML is the foundation of every website on the internet. Every web page you open—whether it is a
blog, shopping site, or social media platform—uses HTML to display its content.
